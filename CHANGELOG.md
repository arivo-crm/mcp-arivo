# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - Current

### Added
- Added product and product category management
- Implemented custom record definitions and custom records
- Added reference data endpoints (users, teams, pipelines, task types)
- Added custom fields metadata retrieval
- Implemented attachment files management
- Enhanced error handling with detailed validation messages
- Support for complex nested data structures (phones, emails, addresses, quote items)
- Task recurrence support

## [1.0.0] - Initial Release

### Added
- Initial release
- Full CRUD operations for contacts, deals, tasks, and notes
- MCP protocol implementation
- CLI support with configuration options
